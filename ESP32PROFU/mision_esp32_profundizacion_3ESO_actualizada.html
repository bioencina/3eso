Arduino IDE

Arduino IDE es el entorno que utilizaremos para escribir, comprobar, compilar y cargar programas en la ESP32.

En el aula: el archivo AppImage de Arduino IDE está disponible en Classroom. Descárgalo desde allí al ordenador.

¿Qué es un AppImage?

Es una forma de distribuir aplicaciones para Linux en un único archivo. En lugar de realizar una instalación tradicional, el archivo contiene lo necesario para ejecutar la aplicación. Normalmente se descarga, se concede permiso para ejecutarlo y después se abre.

  1. Descarga el archivo desde Classroom.
  2. Localízalo en Descargas.
  3. Si no se ejecuta directamente, abre sus propiedades y comprueba que tiene permiso para ejecutarse como programa.
  4. Abre Arduino IDE.

¿Qué es una ESP32?

La ESP32 es una familia de microcontroladores que permite construir sistemas electrónicos programables. Las placas de desarrollo ESP32 incorporan el microcontrolador y otros componentes que facilitan alimentarlo, programarlo y conectarlo con sensores y actuadores.

Entradas
Sensores, pulsadores y señales del entorno.
Procesamiento
El programa toma decisiones con los datos.
Salidas
LED, motores, pantallas, relés...
Comunicación
Según el modelo, Wi‑Fi, Bluetooth y buses de comunicación.

Un programa nuevo de Arduino comienza con una estructura parecida a esta:

void setup() {

}

void loop() {

}

setup() se ejecuta al comenzar el programa. Se utiliza para realizar preparaciones y configuraciones que deben hacerse al inicio.

loop() se ejecuta repetidamente mientras la placa está funcionando.

Antes de continuar: decide dónde colocarías una instrucción que inicia una comunicación una sola vez y dónde colocarías una lectura de temperatura que debe repetirse.

Instala el soporte para ESP32

Arduino IDE puede programar muchas placas diferentes. Antes de utilizar nuestra ESP32 debes instalar en el IDE el paquete que permite reconocer y programar esta familia de placas.

  1. Abre Boards Manager / Gestor de placas.
  2. En el buscador escribe esp32.
  3. Busca esp32 by Espressif Systems.
  4. Pulsa Install / Instalar. Si aparece installed, ya está instalado.
Importante: esto no es una librería para un sensor. Es el paquete de placas que permite que Arduino IDE pueda trabajar con la ESP32.

Selecciona la placa correcta

Al instalar el paquete aparecerán muchas placas. Para esta actividad debes seleccionar:

ESP32 Dev Module

Selecciona el puerto

El puerto es la conexión lógica que utiliza el ordenador para comunicarse con la ESP32 mediante USB.

  1. Observa los puertos disponibles antes de conectar la placa.
  2. Conecta la ESP32 por USB.
  3. Vuelve a abrir la lista de puertos.
  4. El puerto nuevo suele ser el de tu ESP32. En Linux puede aparecer como /dev/ttyUSB0 o /dev/ttyACM0.
  5. Selecciona ese puerto.
Antes de continuar: comprueba que tienes seleccionados ESP32 Dev Module y el puerto de tu placa.

Este es tu primer programa escrito en texto. No tienes que conocer todavía la sintaxis: vamos a aprenderla mientras construimos el programa.

void setup() {

}

void loop() {

}

setup() se ejecuta una vez al arrancar o reiniciar la placa. Aquí prepararemos el sensor y la comunicación con el ordenador.

loop() se ejecuta continuamente. Aquí leeremos la temperatura y mostraremos nuevas medidas.

Las llaves { y } delimitan las instrucciones de cada función. Muchas instrucciones de Arduino/C++ terminan con ;.

¿Qué es una librería?

Una librería contiene código ya preparado que podemos utilizar. Para trabajar con el DHT11 no vamos a programar desde cero la comunicación con el sensor: utilizaremos una librería.

  1. Abre Library Manager / Gestor de bibliotecas.
  2. Busca la librería para sensores DHT de Adafruit.
  3. Instálala. Si Arduino IDE solicita instalar dependencias necesarias, acéptalas.

Incluir la librería

La llamada se escribe al principio del programa, antes de setup():

#include <DHT.h>

void setup() {

}

void loop() {

}

#include indica que nuestro programa necesita utilizar esa librería.

Indicar sensor y pin

#define DHTPIN NUMERO_DEL_PIN
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

DHTPIN representa el GPIO al que está conectado DATA. DHTTYPE indica que utilizamos un DHT11. En DHT dht(DHTPIN, DHTTYPE) creamos un objeto llamado dht y le pasamos esos dos datos como parámetros.

No inventes NUMERO_DEL_PIN: utiliza el GPIO indicado para el montaje.

En setup() iniciaremos las cosas que necesitamos preparar una sola vez.

Iniciar el DHT11

dht.begin();

Iniciar la comunicación con el ordenador

Serial.begin(115200);

115200 es la velocidad de comunicación. Más adelante tendrás que seleccionar esa misma velocidad en el Monitor Serie.

Ejemplo de setup()

void setup() {
    Serial.begin(115200);
    dht.begin();
}
Piensa: ¿por qué estas instrucciones pertenecen a setup() y no a loop()?

Para pedir al sensor una medida utilizamos una función:

dht.readTemperature()

Los paréntesis forman parte de la llamada. En este caso no introducimos parámetros dentro de ellos. La función devuelve la temperatura medida.

Tenemos que guardar ese resultado en una variable:

float temperatura = dht.readTemperature();
ParteSignificado
floatTipo de dato que admite números con decimales.
temperaturaNombre de la variable.
=Guarda el resultado de la derecha en la variable.
dht.readTemperature()Realiza la lectura y devuelve la temperatura.

El DHT11 también puede devolver humedad:

float humedad = dht.readHumidity();

En este primer reto céntrate en la temperatura. La humedad será una posible ampliación.

Para mostrar el valor:

Serial.println(temperatura);

Si quieres que la salida sea más clara:

Serial.print("Temperatura: ");
Serial.print(temperatura);
Serial.println(" °C");

print continúa escribiendo en la misma línea. println escribe y después cambia de línea.

Abre el Monitor Serie

  1. Compila el programa.
  2. Cárgalo en la ESP32.
  3. Abre Serial Monitor / Monitor Serie.
  4. Selecciona 115200 baud, porque debe coincidir con Serial.begin(115200).
  5. Observa los datos que envía la placa.

loop() se repite muy rápidamente. Para no intentar leer el DHT11 continuamente utilizaremos:

delay(2000);

delay recibe un parámetro expresado en milisegundos. 2000 ms son 2 segundos.

Compara: delay(2000) recibe un parámetro. dht.readTemperature() no recibe ninguno, pero devuelve un valor.

Ya tienes todas las instrucciones necesarias

Ahora debes construir tú el programa. No necesitas adivinar sintaxis: vuelve a los apartados anteriores cuando no recuerdes una instrucción.

  1. Incluye DHT.h.
  2. Define el GPIO del sensor.
  3. Indica que utilizas un DHT11.
  4. Crea el objeto dht.
  5. En setup(), inicia Serial y el sensor.
  6. En loop(), lee la temperatura y guárdala en una variable float.
  7. Muestra texto, temperatura y unidad °C.
  8. Espera 2 segundos.
  9. Compila y corrige los errores que aparezcan.
  10. Carga el programa en la ESP32.
  11. Abre el Monitor Serie a 115200.
Has terminado cuando el Monitor Serie muestra periódicamente la temperatura del aula y puedes explicar qué hace cada parte de tu programa.

No compila: lee el primer error. Revisa nombres, mayúsculas, ;, paréntesis, llaves y librería.

No reconoce DHT: comprueba la instalación de la librería y #include <DHT.h>.

Compila pero no carga: revisa ESP32 Dev Module, puerto, cable USB y conexión.

Monitor Serie vacío: comprueba Serial.begin(115200), las instrucciones Serial.print... y que el monitor esté a 115200.

Aparece NaN: no se ha obtenido una lectura numérica válida. Revisa GPIO, DHT11, conexiones y tiempo entre lecturas.

Antes de consultar: explica a la profesora si compila, si carga, qué aparece en el Monitor Serie y cuál es el primer mensaje de error.

🔒 Zona de comprobación docente

Esta zona sirve para que la profesora pueda consultar rápidamente una solución de referencia cuando haya que diagnosticar un error.

Nota: la solución definitiva debe adaptarse al modelo exacto de ESP32 y al sensor exacto. Hasta que se definan, no se muestra un programa que pueda inducir a conexiones o librerías incorrectas.

#include <DHT.h>

#define DHTPIN NUMERO_GPIO
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
    Serial.begin(115200);
    dht.begin();
}

void loop() {
    float temperatura = dht.readTemperature();

    Serial.print("Temperatura: ");
    Serial.print(temperatura);
    Serial.println(" °C");

    delay(2000);
}
